# Paper GPT

用于 Zotero 的论文阅读与翻译插件，集成 ChatGPT 网页对话、PDF 翻译、标注、笔记及常用文库工具。

**当前版本：1.6.5**。主要实机验证环境为 **Windows + Zotero 10.0.6**；安装声明支持 Zotero 9 至 10.0.x，其他平台尚未逐项验证。

## 功能

- **选文翻译与问答**：选择 PDF 文字后翻译、提问，或把回复写入下划线标注和笔记。
- **全文翻译**：按正文段落和图注分批翻译，自动写入对应标注，支持停止和继续。
- **会话管理**：每篇 PDF 保留自己的阅读会话，通用任务共用“AI 摘要”。
- **AI 标签与简记**：支持多选文献，生成后自动保存；摘要缺失时尝试读取本地 PDF。
- **期刊数据**：通过 easyScholar 查询影响因子、JCR / 中科院分区，支持多选更新。
- **阅读记录**：记录阅读时长和浏览页覆盖率。
- **阅读辅助**：提供论文总结、AI 阅读笔记、大纲、文献对比等指令。

期刊、阅读记录、AI 标签和简记不依赖 Style 插件运行，但不代表替代 Style 的全部功能。

## 安装

1. 下载 [Paper-GPT-1.6.5.xpi](./Paper-GPT-1.6.5.xpi)。在 GitHub 文件页面选择下载原始文件。
2. 打开 Zotero → **工具 → 插件**。
3. 点击齿轮 → **从文件安装插件**，选择 XPI。
4. 完成安装后重新打开 Zotero。

请安装 XPI，不要把 GitHub 仓库 ZIP 当作插件安装。已安装同一插件的用户可直接覆盖安装，不需要先卸载。

## 首次配置

点击主文库工具栏或 PDF 侧栏中的 Paper GPT，进入 **设置 → 新手引导 / 基础配置**：

1. 在侧栏 ChatGPT 网页中登录自己的账号。
2. 创建或选择自己的 ChatGPT 项目，复制项目主页链接并保存。
3. 需要期刊查询时，再填写自己的 easyScholar Secret Key；不需要可跳过。

项目主页链接格式：

    https://chatgpt.com/g/g-p-项目编号/project

单个聊天的 /c/ 链接不能代替项目主页。插件不预置私人项目，不附带账号或密钥。AI 功能使用已登录的网页，不要求 OpenAI API 密钥。

## 使用

### 顶部操作栏

| 按钮 | 用途 |
| --- | --- |
| 指令选择器 | 选择翻译、全文翻译、总结等任务 |
| 发送 | 执行所选任务 |
| 跟进 | 在当前 ChatGPT 网页输入框继续提问 |
| 填入 | 只填入网页草稿，检查后自行发送 |
| 说明 | 查看各项功能的解释与使用方式 |
| 设置 | 配置项目、保存方式、期刊及阅读工具 |

### 选文翻译与标注

在 PDF 中选中文字，使用弹出工具：

- **翻译/标注**：把译文写入对应下划线标注的评论。
- **仅问答**：只在网页显示回复。
- **写入笔记**：将结果保存为笔记。

### 全文翻译

打开有可定位文字的本地 PDF，选择 **全文翻译 → 发送**。

插件结合分栏、缩进和行距恢复段落，主要翻译正文和图注，通常跳过参考文献、图内零散文字、页码、页眉和关键词。识别受 PDF 排版和文字层质量影响，建议检查结果。

长段落在句末或词语边界分批发送，收齐译文后合并为一个原段落标注；跨页段落按页保存。可以停止任务，已保存内容保留，再次运行会核对原文、位置和完成标签，跳过已完成段落。

已兼容公式转义造成的返回格式错误；必要时逐段有限重试。未收齐的长段落不写成半截标注，发送状态不明确时不会盲目重发。

### 期刊属性

在 **设置 → 期刊与阅读工具 → 期刊数据设置** 中保存自己的 easyScholar 密钥。

选中一篇或多篇文献，右键 **Paper GPT → 查询或更新期刊属性**。在文献列表表头右键，开启 **期刊评级** 列。

字段取决于账号权限、额度和数据源，缺失字段留空。查询日期不等于评级统计年份，不改写论文标题等其他字段。

### AI 标签与简记

选择 **1–10 篇文献**，右键 **Paper GPT → AI 生成标签 / AI 生成简记**，或从期刊与阅读工具中进入。

标签直接追加为 Zotero 原生标签，保留已有标签；简记直接写入 **简记** 列，不要求二次确认。

优先使用条目摘要；缺失时尝试读取本地 PDF 前 8 页的摘要或原文片段。无法读取的文献单独提示，其余继续。标签、简记和其他通用任务共用“AI 摘要”会话；PDF 阅读、翻译和问答使用各自论文的会话。

### 阅读记录

打开主窗口的 PDF 标签页后自动记录；窗口失焦、空闲或暂停记录时不累计。在列表表头右键开启 **阅读时长 / 阅读进度**。

进度表示浏览页覆盖率，不代表理解程度；独立阅读窗口、EPUB 和网页不在当前计时范围内。

### 删除标注

标注三个点菜单中的 **删除这个 PDF 的所有标注** 会删除当前 PDF 的全部可编辑原生标注，**包括手工标注**。会先显示名称和数量，确认后才执行，不是只删除 AI 译文。

## 常见问题

**提示没有权限或会话不存在**

确认侧栏登录了正确账号、项目可访问，并检查配置的项目主页地址。插件先核实项目列表，确认缺失后才创建会话。登录失效、列表未加载完整或同名会话有歧义时会暂停发送。

**PDF 没有摘要或可读文字**

条目摘要缺失时会尝试读取本地 PDF。扫描件需要先做 OCR；附件未下载、密码限制或文字层损坏时，可能无法获取可靠内容。

**全文翻译中断或超时**

检查网络、网页加载、账号额度，以及未发送草稿或正在生成的回复。再次运行可继续处理未完成段落；发送状态不明确时先检查网页，避免重复提交。

**大量标注时仍卡顿**

新版减少下划线绘制数量、重复刷新和后台坐标复制。旧标注不会自动重新分段或合并；PDF 本身及其他插件也可能影响速度。不要为加速而误删手工标注。

## 更新

安装新版本 XPI 并重新打开 Zotero即可更新同一插件。当前没有联网自动更新服务，重开 Zotero 不会自动下载仓库改动。

## 数据说明

- AI 操作将当前任务所用的文献信息、选文或提取的正文发送到登录的 ChatGPT 网页。
- 期刊查询将期刊名及密钥发送给 easyScholar。
- 阅读记录和简记保存在本地；标签、笔记、标注写入 Zotero，后续同步由自己的 Zotero 设置决定。
- 本仓库不包含个人文库、PDF、登录 Cookie、密钥和个人会话记录。

## 源码与构建

    PaperGPT/
    ├── README.md
    ├── Paper-GPT-1.6.5.xpi
    ├── build.py
    └── src/

普通用户只需安装 XPI。修改源码后，安装 Python 3，在仓库根目录运行：

    python build.py

生成的 XPI 位于根目录，无需额外 Python 包。也可以指定输出位置：

    python build.py --output Paper-GPT-custom.xpi

src/manifest.json 位于生成的 XPI 根目录。后续发布请递增 manifest 中的版本号，并更新 README 的版本和下载文件名。

分享版在独立 Windows Zotero 10.0.6 配置中直接加载 XPI，通过 74 项原生验证。测试中的 AI 传输使用模拟回复，不代表每个账号的实际生成质量和速度；ChatGPT 网页变化可能影响运行。

反馈请提供 Zotero 版本、插件版本、触发步骤和错误截图，遮住账号、密钥及不打算公开的论文内容。
