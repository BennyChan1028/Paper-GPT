# Paper GPT

用于 Zotero 的论文阅读与翻译插件，集成 ChatGPT 网页对话、PDF 翻译、标注、笔记及常用文库工具。

**当前版本：1.6.19**。主要实机验证环境为 **Windows + Zotero 10.0.6 / 10.0.7**；安装声明支持 Zotero 9 至 10.0.x，其他平台尚未逐项验证。

## 功能

- **选文翻译与问答**：选择 PDF 文字后翻译、提问，或把回复写入下划线标注和笔记。
- **全文翻译**：通过 DeepSeek API 按正文段落和图注分批翻译，自动写入对应标注，支持停止和继续。
- **中文与双语 PDF**：一次翻译生成纯中文版及左英文、右中文的逐页对照版，自动添加到对应论文下。
- **会话管理**：每篇 PDF 保留自己的阅读会话，通用任务共用“AI 摘要”。
- **AI 标签与简记**：支持多选文献，生成后自动保存；摘要缺失时尝试读取本地 PDF。
- **期刊数据**：通过 easyScholar 查询影响因子、JCR / 中科院分区，支持多选更新。
- **阅读记录**：记录阅读时长和浏览页覆盖率。
- **阅读辅助**：提供论文总结、AI 阅读笔记、大纲、文献对比等指令。

## 安装

1. 下载 [Paper-GPT-1.6.19.xpi](./Paper-GPT-1.6.19.xpi)。在 GitHub 文件页面选择下载原始文件。
2. 打开 Zotero → **工具 → 插件**。
3. 点击齿轮 → **从文件安装插件**，选择 XPI。
4. 完成安装后重新打开 Zotero。

请安装 XPI，不要把 GitHub 仓库 ZIP 当作插件安装。已安装同一插件的用户可直接覆盖安装，不需要先卸载。

## 首次配置

点击主文库工具栏或 PDF 侧栏中的 Paper GPT，进入 **设置 → 新手引导 / 基础配置**：

1. 在侧栏 ChatGPT 网页中登录自己的账号。
2. 创建或选择自己的 ChatGPT 项目，复制项目主页链接并保存。
3. 需要期刊查询时，再填写自己的 easyScholar Secret Key；不需要可跳过。

项目主页链接格式：

    https://chatgpt.com/g/g-p-项目编号/project

单个聊天的 /c/ 链接不能代替项目主页。插件不预置私人项目，不附带账号或密钥。网页问答、选文翻译及文库 AI 工具使用已登录的 ChatGPT。翻译本页、全文译文批注和中文 / 双语 PDF 改用 DeepSeek API，不需要 ChatGPT 登录或项目链接。

### DeepSeek 翻译 API

1. 打开 Paper GPT → **设置 → DeepSeek 翻译 API**。
2. 在本机密码框填写自己的 API Key，选择模型，然后点击 **保存 API 设置**。留空保存会保留已有密钥。
3. 点击 **测试连接**，成功后即可使用“翻译本页”“全文翻译”“全文翻译为 PDF”。测试会产生少量 API 用量。

默认模型为 DeepSeek Flash，也可选 DeepSeek V4 Pro，使用官方地址 `https://api.deepseek.com/chat/completions`。模型名称及调用方式参见 [DeepSeek 官方文档](https://api-docs.deepseek.com/)。翻译采用非思考模式和 JSON 返回；API 按所选模型用量计费，与 ChatGPT 网页订阅独立。

密钥仅保存在本机 Zotero 密码管理器中，设置不会回显已有密钥；不会写入源码、偏好文件、翻译缓存、PDF 任务文件或分享包。可在同一设置中清除。请勿把密钥粘贴到 GitHub、问题反馈或公开聊天。

这三种翻译均直接请求 DeepSeek，不操作 ChatGPT 输入框或核实对话。未配置密钥、余额不足、请求受限或连接失败时会暂停，不回退到 ChatGPT 网页，也不自动重复有计费可能的请求。超时重试可能产生额外费用。仅收到并验证完整译文后才写入；原有批注或旧 PDF 在失败时保留。

## 使用

### 顶部操作栏

| 按钮 | 用途 |
| --- | --- |
| 指令选择器 | 选择翻译、全文翻译、总结等任务 |
| 发送 | 执行所选任务 |
| 跟进 | 在当前 ChatGPT 网页输入框继续提问 |
| 填入 | 只填入网页草稿，检查后自行发送 |
| 说明 | 查看各项功能的解释与使用方式 |
| 设置 | 配置项目、保存方式、期刊及阅读工具 |

### 选文翻译与标注

在 PDF 中选中文字，使用弹出工具：

- **翻译并标注**：把译文写入对应下划线标注的评论。
- **仅翻译**：只在网页显示译文，不新增或修改标注，也不保存笔记；选择其他指令时显示“仅问答”。
- **写入笔记**：将结果保存为笔记。

### 我的常用

打开左上方的快捷指令菜单，最前面就是 **我的常用**。默认包含翻译、翻译本页、全文翻译为 PDF、全文翻译、摘要总结和 AI 大纲。

点击功能右侧的星标，加入或移出我的常用；偏好会保留到下次启动。原来的功能分类继续保留，搜索也能查找常用功能。编辑已收藏指令的名称后，收藏会跟随新名称。

### 翻译本页

配置 DeepSeek API 后，切到目标 PDF 页面，选择 **翻译本页 → 发送**。插件将同页正文段落和图注合并发送，超过翻译批次预算才拆批，直接把译文写入原文下划线批注，无需预先选中文字。

重翻时只替换本页带有 Paper GPT 翻译标记的旧译文，保留手动批注和其他页面的批注。收齐整页译文后一次保存；回复或写入失败时保留旧译文。处理中翻页不会改变本次目标页。

### 全文翻译

配置 DeepSeek API 后，打开有可定位文字的本地 PDF，选择 **全文翻译 → 发送**。按页依次处理；单页较长时按段落继续分批，不一次发送整篇文档。已完成页面跳过，部分完成的页面只补充缺失译文，保留手动批注。

插件结合分栏、缩进和行距恢复段落，主要翻译正文和图注，通常跳过参考文献、图内零散文字、页码、页眉和关键词。识别受 PDF 排版和文字层质量影响，建议检查结果。

长段落在句末或词语边界分批发送，收齐译文后合并为一个原段落标注；跨页段落按页保存。可以停止任务，已保存内容保留，再次运行会核对原文、位置和完成标签，跳过已完成段落。

已兼容公式转义造成的返回格式错误；必要时逐段有限重试。未收齐的长段落不写成半截标注，发送状态不明确时不会盲目重发。

### 全文翻译为中文与双语 PDF

打开原论文，在顶部指令中选择 **全文翻译为 PDF → 发送**，自动生成两份文件并保存到原 PDF 所在文件夹：

| 文件 | 内容 |
| --- | --- |
| **中文-原文件名.pdf** | 保留原页面结构的纯中文版 |
| **双语-原文件名.pdf** | 每页左侧英文原文、右侧对应中文译文 |

两份文件共用同一次翻译，不为双语版再次发送翻译请求。双语版每个横向页面对应原文的一页，页面宽度为原页的两倍、高度保持原样；文字仍可选择和搜索，图表、公式随各自原页保留。不同尺寸、旋转页和裁剪页按其实际可见页面配对，原有书签保持对应页码。

完成后，两份文件自动添加为同一论文下的 PDF 附件，分别提供 **打开中文 PDF** 和 **打开双语 PDF**。原 PDF 是独立条目时，两份文件会加入相同分类。重新导出时各自沿用固定名称，新版保存并添加成功后，清理对应格式的旧附件和文件，不再新增 (2) 等编号副本；两种格式不会互相删除。

插件通过已配置的 DeepSeek API，将同一页待译段落合并发送，再由本机排版引擎生成 PDF。只有整页超过翻译批次预算时才拆批，不再每段单独等待。

- 原英文 PDF、其批注及其他无关附件保持不变。替换范围限于同一原文、同一输出格式的历史附件；删除旧输出附件也会删除该旧附件上的批注。导出文件保存在原文件目录，同时作为 Zotero 管理的附件副本添加到文库，以便正常管理和同步。原文件的手工批注不复制到新双语页面。
- 同一论文下符合“中文-原文件名”或“双语-原文件名”及旧编号格式的历史副本，会在对应格式下一次成功保存后清理；每种格式分别记录来源，便于识别以后被改名的附件。独立 PDF 的历史副本若没有来源记录，不在整个文库中按名称猜测删除。
- 新 PDF 完整生成并通过校验后才替换对应旧版。如果某种格式保存或添加附件失败，会回退保留该格式的旧版，另一格式可正常完成；可在失败文件下点击 **重新保存并添加** 单独重试，无需重新翻译或排版。部分旧文件因占用而清理失败时会明确提示，并提供 **清理旧版本** 按钮。
- 纯中文版保留原页数、页面尺寸、分栏、图片及公式；双语版将对应的两页左右并排。正文和图注在原区域重新排字；自动识别参考文献标题后跳过文献列表并保留原文，附录恢复翻译。
- 译文在原有段落区域内自动选择能完整容纳的字号；按实际字形边界检查，不通过裁切或省略文字来放下。表格正文采用同一张表内统一的字号，保留公式与上下标的相对大小；修复部分 Word 导出 PDF 的行背景遮住重排译文的问题。
- 中文长度和字体与英文不同，换行、字距和段落高度可能变化，不能保证像素级一致。复杂公式、跨栏表格和扫描件需要人工检查；扫描件建议先 OCR。
- 排版引擎使用独立短临时目录和固定的短文件名，避免长论文标题重复拼接造成 Windows 路径过长；完成、失败或取消时清理该任务自己的临时文件。导出文件使用“中文-”和“双语-”前缀。
- 可停止后重新运行；每批已收齐的完整段落会写入本机缓存，恢复时只发送缺失段落。PDF 缓存按 DeepSeek 模型独立保存，不混用以前的网页翻译缓存。只有完整通过编号、公式占位符及页数校验后才保存最终 PDF。
- 按实际编码后的完整输入计算批次长度，使用最多 8,000 字符的保守 API 批次预算（这是插件的分批策略，不代表服务或模型的上限）。超长段落拆批后仍按原段落回填。
- 选择 **全文翻译** 仍然执行原来的下划线批注流程，两种输出互不替代。

**首次安装这个可选功能**：先安装 Python 3.12，再双击仓库中的 **安装 PDF 导出组件.cmd**。它安装独立的本机 BabelDOC 环境并登记到 Zotero，需要在上述设置中配置 DeepSeek API；无需安装 zotero-pdf2zh 插件。首次运行需联网下载版面模型和字体；之后使用本地缓存。建议为排版预留约 4 GB 可用内存。环境位于分享文件夹的 runtime，源文与译文缓存位于 Zotero 数据目录的 paper-gpt/pdf-export，不要上传这些运行数据。

macOS / Linux 或希望指定目录时，在 Python 3.10–3.13 下运行 `python setup-pdf-export.py`；可通过 `--profile` 和 `--runtime` 指定配置目录和环境目录。第三方组件说明见 [THIRD_PARTY.md](./THIRD_PARTY.md)。

### 期刊属性

在 **设置 → 期刊与阅读工具 → 期刊数据设置** 中保存自己的 easyScholar 密钥。

选中一篇或多篇文献，右键 **Paper GPT → 查询或更新期刊属性**。在文献列表表头右键，开启 **期刊评级** 列。

字段取决于账号权限、额度和数据源，缺失字段留空。查询日期不等于评级统计年份，不改写论文标题等其他字段。

### AI 标签与简记

选择 **1–10 篇文献**，右键 **Paper GPT → AI 生成标签 / AI 生成简记**，或从期刊与阅读工具中进入。

标签直接追加为 Zotero 原生标签，保留已有标签；简记直接写入 **简记** 列，不要求二次确认。

优先使用条目摘要；缺失时尝试读取本地 PDF 前 8 页的摘要或原文片段。无法读取的文献单独提示，其余继续。标签、简记和其他通用任务共用“AI 摘要”会话；PDF 阅读、翻译和问答使用各自论文的会话。

### 阅读记录

打开主窗口的 PDF 标签页后自动记录；窗口失焦、空闲或暂停记录时不累计。在列表表头右键开启 **阅读时长 / 阅读进度**。

进度表示浏览页覆盖率，不代表理解程度；独立阅读窗口、EPUB 和网页不在当前计时范围内。

### 删除标注

标注三个点菜单中的 **删除这个 PDF 的所有标注** 会删除当前 PDF 的全部可编辑原生标注，**包括手工标注**。会先显示名称和数量，确认后才执行，不是只删除 AI 译文。

## 常见问题

**提示没有权限或会话不存在**

确认侧栏登录了正确账号、项目可访问，并检查配置的项目主页地址。插件先核实项目列表，确认缺失后才创建会话。登录失效、列表未加载完整或同名会话有歧义时会暂停发送。

**PDF 没有摘要或可读文字**

条目摘要缺失时会尝试读取本地 PDF。扫描件需要先做 OCR；附件未下载、密码限制或文字层损坏时，可能无法获取可靠内容。

**全文翻译中断或超时**

检查网络、DeepSeek API 密钥、余额及限流提示。再次运行可继续处理未完成段落；超时或连接中断时，请注意再次请求可能计费。

**大量标注时仍卡顿**

新版减少下划线绘制数量、重复刷新和后台坐标复制。旧标注不会自动重新分段或合并；PDF 本身及其他插件也可能影响速度。不要为加速而误删手工标注。

## 数据说明

- 翻译本页、全文译文批注及 PDF 导出将待译正文和图注发送到 DeepSeek 官方 API；其他网页 AI 操作将对应文献信息、选文或原文材料发送到登录的 ChatGPT 网页。
- 期刊查询将期刊名及密钥发送给 easyScholar。
- 阅读记录和简记保存在本地；标签、笔记、标注写入 Zotero，后续同步由自己的 Zotero 设置决定。
- 本仓库不包含个人文库、PDF、登录 Cookie、密钥和个人会话记录。

## 1.6.6 更新

- AI 大纲、全文总结、AI 阅读笔记、文献对比、Canvas、长选文、笔记及摘要等操作根据实际提示词长度自动分批。大纲和全文标注核对页码后在本地合并；总结类任务先提取事实笔记，再逐级压缩并综合；翻译类逐批翻译后汇总，不改成摘要。
- 每次网页请求采用最多 8000 个 JavaScript 字符的应用预算（包含提示词），不是 ChatGPT 官方上限；全文逐段翻译沿用更小的 4000 字符预算。网页如声明更小的输入框限制则拒绝超量，填入后也核对是否完整，不自动重发发送状态不明确的消息。
- 摘要总结直接读取条目摘要；缺失时尝试本地 PDF 前 8 页材料，无需先选中文字，不自动改写原摘要字段。自定义提示词保留；只迁移未修改的旧默认命令。
- 论文标题下只显示一条实时状态，移除重复的“本 PDF · 已核实会话”显示。

### 关于网页输入框长度

这里检查的是网页输入框一次能接收的文字量，不把模型上下文容量当成输入框限制。插件读取当前输入框的 maxlength 属性；如果网页没有明确声明，则记录为未知，使用保守的 8000 字符单批应用预算。填入后核对文字是否完整，拒绝继续发送被截断的内容。该预算不是已确认的 ChatGPT 网页真实上限。
